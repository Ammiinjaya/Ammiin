⚙️ Konfigurasi Cloudinary & Firestore

Buka file js/firebase-config.js lalu masukkan Cloud Name dan Upload Preset dari Cloudinary.

Langkah Cepat (100% Gratis Tanpa Kartu):

1. Firestore: Di Firebase Console, klik Firestore Database → Create database → Start in test mode.

2. Cloudinary: Buka cloudinary.com (daftar via Google) → copy Cloud name.

3. Di Cloudinary Settings ⚙️ → Upload presets → klik Add upload preset → ubah Signing mode ke Unsigned → Save.

4. Masukkan keduanya ke js/firebase-config.js.
